# QueryCraft: Frontend Prototype

A responsive, interactive landing page and UI prototype for **QueryCraft**, an AI-powered text-to-SQL generation engine. This project was developed as a frontend engineering training task to demonstrate modern web layout architecture and UI/UX implementation.

## 🚀 Live Demo
[View the Live Prototype Here](https://abhishekayachit33-code.github.io/QueryCraft/)

## 🎯 Project Overview
This repository contains the static frontend interface for the QueryCraft application. It is designed to be a sleek, high-conversion landing page that transitions smoothly into a functional web application interface. 

The current deployment features a "Mock UI" for the query generator, simulating how the system will eventually interact with an LLM backend (like a fine-tuned Llama-3-8B model) to return schema-aware SQL.

## 🛠️ Technical Stack
* **HTML5:** Semantic structuring for accessibility and SEO.
* **CSS3:** * CSS Variables (`:root`) for a scalable design system.
  * Flexbox & CSS Grid for fluid, responsive layouts.
  * Advanced pseudo-elements (`::after`) and transitions for interactive hover states.
* **Vanilla JavaScript:** * DOM manipulation for mobile navigation toggling.
  * Asynchronous simulation for the query generation UI.

## 📱 Features
* **Fully Responsive Design:** Adapts seamlessly across desktop, tablet, and mobile devices utilizing a mobile-first media query approach.
* **Interactive Generator UI:** A dual-pane interface featuring a user input area and a dark-mode, syntax-highlighted output block for generated code. Accessible via the "Try QueryCraft Engine" call-to-action.
* **Micro-interactions:** Smooth scrolling, customized hover states, and dynamic button feedback to enhance the user experience.
